# Osmo Action 1 RTMP Firmware

为初代 **DJI Osmo Action（AC101）** 开发的自定义固件，让相机通过 Wi-Fi STA 推送 RTMP，并在浏览器中管理直播。

RTMP streaming firmware for the original DJI Osmo Action, with Wi-Fi STA, bilingual web controls, and a touchscreen Snake game.

这是社区修改项目，与 DJI 官方无关联。

**[下载固件 / Releases](https://github.com/m0h31h31/osmo-action1-rtmp/releases/latest)** · [配置示例](examples/wifi.conf.example) · [构建说明](docs/BUILD.md) · [实机验证记录](docs/v21-validation.json)

## 功能

- **RTMP 推流**：网页保存地址和码率，手动启动、停止并查询状态。开机不会自动推流。
- **Wi-Fi STA**：从内存卡 `wifi.conf` 读取配置；自定义网络功能仅保留 STA，不提供自定义 AP。
- **原厂接管**：网页关闭 STA 后，完整关机再开机，由原厂系统管理 Wi-Fi，可使用 DJI Mimo。
- **双语网页**：支持简体中文和 English，浏览器记住所选语言。
- **原生贪吃蛇**：从相机系统设置页打开，上下左右滑动控制，支持开始、重新开始和退出。
- **USB 功能保留**：USB 网卡模块与工具仍在固件中，默认不启动，网页不显示其控制项。

本项目不提供直接作为 UVC 摄像头接入 OBS 的功能。

## 安装

请使用匹配 AC101 的发布包，先备份内存卡中的重要文件。

1. 从 Releases 下载并解压固件 ZIP。
2. 将 BIN 和包内调试标记文件放入内存卡根目录。
3. 按下一节配置 `wifi.conf`。
4. 保持电量充足和供电稳定，正常关机后再开机。
5. 出现升级进度后等待完成，不拔电池或强制断电。
6. 回到拍摄预览后，检查联网及网页状态。

发布包的 `validation.json` 记录固件校验值和验证范围。请勿把不同版本的多个升级 BIN 同时放在卡根目录。

## 配置 Wi-Fi

在内存卡根目录创建 UTF-8 文本文件 `wifi.conf`：

```ini
WIFI_MODE=sta
ESSID="Your Wi-Fi name"
PASSWORD="Your Wi-Fi password"
```

支持 WPA/WPA2 个人网络、8–63 字节密码或 64 位十六进制 PSK。开放网络使用 `PASSWORD=`。支持 LF 和 CRLF 换行。

配置按字面读取，不执行命令或展开变量。请勿在值末尾加行内注释。暂不支持企业认证、WEP 或纯 WPA3 网络。

开机后，从路由器客户端列表查找相机地址，访问 `http://<相机IP>/`。每台相机独立保存 STA MAC 地址。缺失或无效的 STA 配置不会自动创建自定义热点。

## 管理 STA 开关

网页中的开关修改在**完整关机、再开机**后生效，熄屏和唤醒不会应用修改。

关闭 STA 后，相机不再连接配置的路由器，原来的网页地址不可用。Wi-Fi 交由原厂系统管理，可使用 DJI Mimo。被移除的是自定义 AP 功能，原厂连接所需的热点仍保留。

### 从内存卡恢复 STA

1. 关闭相机。
2. 删除内存卡根目录的 `OA_STA_DISABLE`。
3. 如果存在旧版 `NO_WIFI` 文件，也将其删除。
4. 确认 `wifi.conf` 有效，再开机。

无卡启动时由原厂系统管理 Wi-Fi。

## RTMP 与 OBS

1. 在电脑或服务器运行 RTMP 接收服务，例如 MediaMTX。
2. 在相机网页中填写接收地址，例如 `rtmp://192.168.1.10:1935/live/osmo`。
3. 保存配置并点击“启动推流”。
4. 在 OBS 添加对应的接收来源。

固件中的默认接收地址来自开发环境。首次使用请改为你自己的服务器地址，不要直接沿用默认值。

相机报告“推流中”不代表服务器已收到画面，应同时检查接收端。低延迟时间戳修正在电脑端运行，**不包含在固件中**。页面显示的 `osmo-lowdelay` 地址只有在对应的电脑接收与修正服务运行时才可用。实际延迟取决于网络、接收服务与 OBS 缓冲设置。

## 原生贪吃蛇

在相机系统设置页点击“贪吃蛇”，开始后在棋盘内滑动转向。无需方向键。相机忙碌或出现真实原厂弹窗时，游戏让出操作。

停用游戏：在内存卡根目录创建空文件 `OA_SNAKE_DISABLE`，完整关机再开机。删除文件并再次完整关机开机可重新启用。加载器检测异常后可能保留故障标记，供排查使用。

## 已验证

当前 AC101 实机完成了：

- 升级及完整关机开机后，STA 自动联网，网页与游戏自动就绪。
- 游戏进入、滑动控制和退出。
- 网页手动启动和停止 RTMP，接收端实际解码视频。
- 关闭 STA 后，Mimo 连接并显示实时预览。
- 删除关闭标记后，重启自动恢复 STA。
- 中英文切换与语言保存；USB 网卡没有自动加载。

长时间录制及原厂 USB 文件传输的完整回归尚未覆盖。

### v21 修复

修复原厂空提示框容器导致“游戏入口可见但无法进入”的问题。真实弹窗与相机忙碌保护仍保留。

## 使用范围与安全

这是包含底层系统改动的修改版固件，不提供官方兼容性或保修承诺。

固件保留**无密码 root Telnet 调试入口**。仅在可信局域网中使用，不要将相机管理端口映射到公网。提交 Issue 或分享日志前，请移除 Wi-Fi 密码、推流密钥及其他私人配置。
